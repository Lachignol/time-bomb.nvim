1. INTRODUCTION					|time-bomb-introduction|

time-bomb.nvim is a timer and Pomodoro manager for Neovim. It displays real-time
floating timers with progress bars and automatic Pomodoro cycles (25/5/25/5/25/15).

Features:
- Custom timers with floating window
- Full Pomodoro cycles with auto-progression  
- 6 progress bar styles
- Pause/resume functionality
- Cycle navigation (next/prev)
- Auto-reposition on resize

2. INSTALLATION					|time-bomb-installation|

With lazy.nvim: >lua
    {
      "Lachignol/time-bomb.nvim",
      config = function()
        require("time-bomb").setup({
          enable_default_keymaps = true,
          timer_color = "lime",
        })
      end,
    }
<
With packer.nvim: >lua
	use {
	  "Lachignol/time-bomb.nvim",
	  config = function()
	    require("time-bomb").setup()
	  end
	}

With vim.pack: >lua
	vim.pack.add({{src = "https://github.com/Lachignol/time-bomb.nvim"}})


	require("time-bomb").setup({
		enable_default_keymaps = true,
		timer_color = "lime",
	})

3. CONFIGURATION					|time-bomb-configuration|

Available options:

*enable_default_keymaps* (boolean)
  Enable default keymaps
  Default: `true`

*keymaps* (table) >
  - `pomodoro_start`: `<leader>tbs` (default) - `:TimeBomb pomodoro`
  - `timer_custom`: `<leader>tbc` (default)   - `:TimeBomb timer`
  - `stop_timer`: `<leader>tbe` (default)     - `:TimeBomb stop`
  - `pause_timer`: `<leader>tbp` (default)    - `:TimeBomb pause`
  - `next_timer`: `<leader>tbn` (default)     - `:TimeBomb next`
  - `prev_timer`: `<leader>tbb` (default)     - `:TimeBomb prev`
<

*position* (table) >lua
Layout options: `"bottom-right"`, `"bottom-left"`, `"top-left"`, `"top-right"`
Margin-values (x and y): must be equal or upper to 0 and is relative to the chosen layout corner (x: horizontal, y: vertical)

Default:
  position = {
	layout = "top-right",            
	margin = { x = 2 , y = 1}, 
  },



*pomodoro_cycles* (array of tables) >
  Custom Pomodoro cycles:
>lua
  {
    { title = "Work", time = "25", style = "normal" },
    { title = "Short-Break", time = "5", style = "mama-lova" },
    { title = "Work", time = "25", style = "cyberpunk" },
    { title = "Short-Break", time = "5", style = "fire" },
    { title = "Work", time = "25", style = "dots" },
    { title = "Long-Break", time = "15", style = "music" }
  }
<
  *Valid-styles*: `"normal"`, `"mama-lova"`, `"cyberpunk"`, `"fire"`, `"dots"`, `"music"`, `"gta"`, `"casino"`, `"zombie"`
<

*timer_color* (string)
  Timer color: `"lime"`, `"blue"`, `"black"`, `"gray"`, `"silver"`, `"white"`, `"fuchsia"`
  Default: `"lime"`

*enable_notification* (boolean)
  Show nvim-notify on timeout
  Default: `false`

*Full-example*: >lua
    require("time-bomb").setup({
      enable_default_keymaps = true,
      enable_notification = true,
      timer_color = "fuchsia",
      position = {
	layout = "top-right",            
	margin = { top = 1, right = 2 }, 
      },
      keymaps = {
        pomodoro_start = "<leader>p",
        timer_custom = "<leader>t",
        stop_timer = "<leader>x",
        pause_timer = "<leader>z",
        next_timer = "<leader>n",
        prev_timer = "<leader>b",
      },
      pomodoro_cycles = {
        { title = "Work", time = "25", style = "normal" },
        { title = "Short-Break", time = "5", style = "mama-lova" },
        { title = "Work", time = "25", style = "cyberpunk" },
        { title = "Short-Break", time = "5", style = "fire" },
        { title = "Work", time = "25", style = "dots" },
        { title = "Long-Break", time = "20", style = "music" },
      },
    })
<

4. COMMANDS						|time-bomb-commands|

:TimeBomb timer [N]						*:timer*
    Start custom N-minute timer.
    Examples: `:TimeBomb timer 5`, `:TimeBomb timer 25`, `:TimeBomb timer` (prompt)

:TimeBomb pomodoro						*:pomodoro*
    Start full Pomodoro cycle from current position.

:TimeBomb stop 						        *:stop*
    Stop current timer immediately.

:Timebomb pause						        *:pause*
    Toggle pause/resume current timer.

==============================================================================

5. KEYMAPS						|time-bomb-keymaps|

Default keymaps (if `enable_default_keymaps = true`):

<leader>tbc  → :TimeBomb timer          (Custom timer)      ~
<leader>tbs  → :TimeBomb pomodoro       (Pomodoro start)    ~
<leader>tbe  → :TimeBomb stop           (Stop timer)        ~
<leader>tbp  → :TimeBomb pause          (Pause/resume)      ~
<leader>tbn  → :TimeBomb next           (Next cycle)        ~
<leader>tbb  → :TimeBomb preva          (Previous cycle)    ~


Customizable via `config.keymaps`.

7. COMMANDS AVANCÉS				|time-bomb-advanced|

:TimeBomb next						*:next*
    Jump to next cycle immediately (skip current).

:TimeBomb prev						*:prev*
    Jump to previous cycle.

*Usage*: Perfect for cycle navigation during Pomodoro sessions.

8. LUA API						|time-bomb-api|

>lua
require("time-bomb").setup(opts)		        *time-bomb.setup()*
    Configure plugin.

require("time-bomb").run_timer(minutes, "TIMER")	*time-bomb.run_timer()*
    Start custom timer.

require("time-bomb").run_timer("nimp", "POMODORO")	*time-bomb.run_pomodoro()*
    Start next Pomodoro cycle.

require("time-bomb").stop_timer()			*time-bomb.stop_timer()*
    Stop current timer.

require("time-bomb").pause_timer()			*time-bomb.pause_timer()*
    Toggle pause/resume.

require("time-bomb").next_cycle()			*time-bomb.next_cycle()*
require("time-bomb").prev_cycle()			*time-bomb.prev_cycle()*
    Navigate cycles.

9. HEALTH CHECK					|time-bomb-health|

`:checkhealth time-bomb`

*Checks*:
- Neovim *0.8+* version
- Config types validation 
- `pomodoro_cycles`: titles ≤ *11chars*, valid styles, times *1-1439min*
- Valid `timer_color` values
- Valid `position.layout` values
- position.margin : x >= 0, y >= 0
- Keymaps status from config

*Auto-fixes* (appliqués silencieusement):
- Invalid styles → `normal`
- Invalid position → `top-right`
- Invalid position.margin values → `x` = 2 `y` = 1,
- Invalid colors → `lime`
- Invalid times → clamped (*1-1439* min)
- Type errors → reset to defaults
- Invalid cycle → first default cycle

*Example-output*:
>lua
	time-bomb.nvim
	  ✓ Neovim version 0.8+
	  
	  CONFIG ERRORS (~3 found):
	  ✗ [error] pomodoro_cycles[2]: title "SuperLongWorkSession" > 11 chars (truncated)
	  ✗ [error] pomodoro_cycles[3]: style "invalid-style" → normal
	  ✗ [error] timer_color: "purple" → lime
	  
	  CONFIG WARNINGS (~1 found):
	  ⚠ [warning] pomodoro_cycles[1] "Work" title > 10 chars (truncated)
	  
	  INFO:
	  ✓ keymaps are set
	  ✓ Configuration: 6 cycles processed
	  
	time-bomb: READY (with 3 auto-fixes)

*Utilisation*:
>lua
	:checkhealth time-bomb                  " Voir toutes les erreurs/warnings"
	:lua require'time-bomb.config'.setup{}  " Re-valider config"

*Notes*:
- The *auto-fixes* are *immediately* applied
- `:checkhealth` shows the *current* status after fixes
